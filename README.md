# Checkout do E-commerce:

## Descrição do projeto:
Projeto desenvolvido em JavaScript para simular o checkout
de um e-commerce, com cálculo do subtotal do carrinho,
contagem de itens e aplicação de cupons de desconto.

O projeto busca evitar a perda de código e organizar
o trabalho colaborativo por meio do Git e do GitHub.

## Estrutura de pastas:
- README.md: documentação do projeto.
- .gitignore: arquivos ignorados pelo Git.
- checkout.js: funções do carrinho, cupons e checkout.

## Como executar:
1. Instale o Node.js;
2. Abra o terminal na pasta do projeto;
3. Execute: node checkout.js.

## Fluxo de branches:
- main: versão inicial e estável do projeto;
- develop: integração das funcões;
- feature/carrinho-laco: desenvolvimento das funções do carrinho;
- feature/validacao-cupom: desenvolvimento das regras de cupons.

## Como o Git evitaria o incidente:
O Git mantém o histórico das alterações e permite que cada
desenvolvedor trabalhe em sua própria branch. Assim, as
modificações podem ser revisadas e integradas pela develop.
Se ocorrer um conflito, ele pode ser resolvido manualmente,
preservando as duas funcionalidades e evitando sobrescrever
o trabalho do colega.
